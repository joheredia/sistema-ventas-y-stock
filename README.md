# Sistema de Ventas y Control de Stock

Aplicación desarrollada en Python con Tkinter y SQLite para la gestión de ventas, inventario y facturación.

## Requisitos

- Python 3.10 o superior
- SQLite3
- Pillow
- ReportLab
- ttkthemes

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/joheredia/sistema-ventas-y-stock.git
cd sistema-ventas-y-stock
```

2. Instalar dependencias:

```bash
pip install -r requirements.txt
```

3. Ejecutar la aplicación:

```bash
python main.py
```

## Características

- Gestión de inventario
- Control de stock
- Registro de ventas
- Generación de comprobantes PDF
- Interfaz gráfica con Tkinter

## Tecnologías utilizadas

- Python
- Tkinter
- SQLite
- ReportLab
- Pillow
- ttkthemes
